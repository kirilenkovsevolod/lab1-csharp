# Лабораторная работа №1 — C# (вариант 9)

«Выполнение простой программы. Типы данных. Организация ввода и вывода данных»

## Состав работы

| Папка | Содержимое |
|---|---|
| `Отчет` | Отчёт по лабораторной работе (DOCX) |
| `Тесты` | Таблицы тестов с анализом достаточности по критериям чёрного и белого ящика (XLSX) |
| `Задача1` | Выражения с инкрементами/декрементами и функция f(x) = sin(x³) + x⁴ + ⁵√(x²+x³) |
| `Задача2` | Принадлежность точки треугольнику с вершинами (-2;0), (0;2), (2;0) |
| `Задача3` | Вычисление выражения ((a+b)³ − (a³+3ab²)) / (3a²b+b³) в типах float и double |

## Запуск

Каждая задача — самостоятельная консольная программа (C#, .NET 9):

- **Visual Studio**: создать консольный проект, вставить содержимое `Program.cs`, Ctrl+F5;
- **или командой**: `dotnet run` из папки проекта.

## Тестирование

Тесты каждой задачи покрывают все классы эквивалентности (включая ошибочные ситуации)
и все ветви программы; для задачи 2 достигнуто покрытие условий уровня MC/DC.
